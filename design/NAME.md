# Name check: MedVerify GH (v2 design)

Checked 25 Oct 2026 (web search).

## Verdict: Real problem. Consider renaming (recommended: **MedCheck GH**)

| Conflict | What it is | Risk |
|---|---|---|
| **“MedVerify — check a medicine’s registration status in Ghana”** (medverify.versatechq.com) | An independent free web app that searches the **FDA Ghana product register** by name or barcode. **Same name, same country, nearly the same job.** | **High.** Judges or users who search the name will find it, and it looks like we copied it |
| MedVerify (India) and a blockchain “MedVerify” Android app; medverify.me | Drug-authentication projects | Medium: a crowded name, hard to own |
| MediCheck (getmedicheck.com) | Blockchain QR/NFC medicine verification | Low/medium |
| mPedigree / Goldkeys (Ghana) | Long-standing Ghanaian scratch-code anti-counterfeit service | Not a name clash, but a well-known local incumbent. Say how we differ: we check **FDA alerts and recalls** from a photo, with no scratch code needed |

## Options (all fit the family: `<Thing>Check GH`)
| Name | Pros | Cons / checks |
|---|---|---|
| **MedCheck GH** (recommended) | A perfect sibling to **ScamCheck GH**: one family, one pattern, easy to say. No Ghana-specific medicine app found under this name | “MedCheck” is used generically elsewhere (an iOS drug-interaction app, medcheck.store in Nigeria). The “GH” suffix and the logo do the distinguishing |
| PackCheck GH | Says exactly what you do (photograph the pack) | Less clearly about medicine |
| BatchCheck GH | Very precise, which pharmacists like | Jargon for patients |
| Keep MedVerify GH | No rework | See the conflict above |

**The design is name-agnostic.** Every screen and token is the same either way. Ready-made **MedCheck GH** v2 lockups (capsule mark, teal), icons and favicons are in `logo/alt-name-medcheck/`. To switch: replace the `logo/` files with those, then search and replace “MedVerify” → “MedCheck” in the copy. The slug `medverify-gh` can stay.

## Taglines
- **Primary:** “Check the batch, not the box.” (A counterfeit can look perfect. The batch number is what FDA alerts list.)
- Alternates: “Snap the pack. Know before you take it.” · “FDA Ghana alerts, in your pocket.” · For pharmacists: “Check before you dispense.”
- Twi (placeholder, **needs native review**): “Hwɛ ansa na woanom” (“look before you drink/take it”).
