# MedVerify GH v2: brand and design system

## Direction: clinical calm
v2 is meant to look like a funded health product (Stripe, Linear and One Medical were the benchmarks), not a hackathon demo. Backgrounds are neutral zinc in both modes. There is **one** teal accent, used for primary actions, focus, links and a thin 2px line at the top of the header. Red, amber and green appear **only** as the verdict colours. The design has no patterns, kente, gold, cream, emoji or playful badges. The look comes from type, whitespace and hairlines.

How it differs from ScamCheck GH (and from v1):

| | ScamCheck GH | MedVerify GH v2 |
|---|---|---|
| Verdict | Tinted verdict card | Neutral card with a **solid colour header strip** and white text |
| Type | Bricolage / Atkinson / JetBrains Mono | **Onest** 600 / **Source Sans 3** / **Geist Mono** |
| Icons | Lucide | **Phosphor** 2.1.1 (regular, plus fill for verdicts) |
| Shape | Their own radii and buttons | 12px hairline cards, **pill** buttons, 8px inputs |
| Progress | Step list | **Checklist pipeline** with status pills, and a horizontal **evidence flow** with a timing bar |

## Palette and theme
- **Light:** bg `#FAFAFA`, surface `#FFFFFF`, sunken `#F4F4F5`, border `#E4E4E7`, text `#111113`. Primary `#0B7A73` (brand.600).
- **Dark:** bg `#111113`, surface `#18181B`, raised `#202023`, border `#27272A`, text `#F4F4F5`. Primary `#5FCDC3` (brand.300) with text `#042826`. Not brand-tinted.
- **Verdicts:** solid colour with white text in both modes. Light: Do not use `#C9302C`, Check first `#B45309`, No alerts found `#15803D`. Dark: `#D2342F`, `#B45309`, `#17834A`.
- Tool colours (NVIDIA green and Tavily blue) appear only in the AI evidence tags and timing bar.

**Theme handling** (`html/_src/partials/head.html`):
1. A `?theme=light|dark` URL parameter previews a mode and is not saved.
2. Otherwise a saved choice in `localStorage['mv-theme']` is used.
3. Otherwise the CSS follows `prefers-color-scheme`.

The toggle button (`.theme-toggle`, calling `mvToggleTheme()`) sets `data-theme` on `<html>` and saves the choice. `tokens.css` writes the dark values twice: in `@media (prefers-color-scheme: dark) :root:not([data-theme='light'])` and in `[data-theme='dark']`. In Tailwind, `dark:` maps to `[data-theme="dark"]`. The logo swaps with `.only-light` and `.only-dark`.

## Typography
- **Onest 600** for display and headings. It covers ɛ and ɔ for Twi.
- **Source Sans 3** for body text.
- **Geist Mono** for batch numbers, timings and model IDs.

| Token | px | Use |
|---|---|---|
| display | 36 | Landing hero (desktop hero is 56px, the one exception) |
| verdict | 30 | "Do not use" |
| h1 / h2 / h3 | 24 / 20 / 18 | Screen titles, sections, card titles |
| body-lg / body | 20 / 18 | Lead text / reading text |
| label / small | 16 | Buttons, field labels, secondary text (16 is the minimum for reading text) |
| overline / mono | 14 | `.t-eyebrow`, chips, batch numbers |

Line height is 1.1 for display (tracking −0.03em), 1.25 for h1 and 1.55 for body.

## Spacing, radius and elevation
- **Spacing** is a 4px scale: 0, 1, 2, 4, 6, 8, 12, 16, 20, 24, 28, 32, 40, 48. All component padding and gaps use it. The mobile gutter is 24px and sections are 40px apart.
- **Radius:** xs 4, sm 6, md 8 (inputs), lg 12 (cards), xl 16, 2xl 20 (verdict, viewfinder), pill (buttons, chips).
- **Shadows** are very subtle zinc in light mode. Dark mode uses 1px white rings instead of shadows.
- **Tap targets:** 48 / 52 / 60px. Max width is 440px on mobile and 1180px on desktop.

## Logo
An upright capsule split in two tones, with a check in the top half: "this medicine was checked". It has no crosses and no patterns.
- `logo/` holds the MedVerify GH set and `logo/alt-name-medcheck/` the MedCheck GH set.
- Each set has the mark (light and dark), wordmark, lockup-light/dark, app icon (square and rounded), adaptive foreground/background/monochrome layers, favicons (svg/ico/32/48) and apple-touch-icon-180.

## Verdict mapping (fixed wording; never "safe")
| Class | Header | Icon | Means |
|---|---|---|---|
| `.verdict--scam` | **Do not use** | warning-octagon-fill | The batch or product matches an FDA Ghana alert, recall or unregistered notice |
| `.verdict--suspicious` | **Check first** | warning-fill | A partial match, or the product could not be confirmed. Ask a pharmacist |
| `.verdict--ok` | **No alerts found** | check-circle-fill | No FDA Ghana alert for this batch. "Not a promise it's right for you." |
| `.verdict--unsure` | We're not sure | question-fill | Low confidence. Treat it as Check first |

Each verdict has a distinct **shape** as well as a colour (octagon, triangle, circle).

## Functional rules (unchanged from v1)
- Tavily searches `site:fdaghana.gov.gh` only.
- **No verdict if the FDA search fails** (see the error state).
- **Never guess an unreadable batch.** The app asks the user to retake the photo or type the batch.
- The "What we read" card is always shown, with a **Fix** link.
- Fixed contacts:
  - **112** (ambulance)
  - **FDA 055 111 2224 / 2225**
  - **adr.fdaghana.gov.gh** and the **Med Safety** app for side effects
- Demo example: **Para Clear Suspension 125, batch L220008** (FDA Ghana alert, 26 June 2023, ethylene glycol), always tagged EXAMPLE.
- States covered:
  - unreadable batch
  - slow network
  - offline
  - FDA search failed
  - low confidence
  - analysing
  - all three verdicts

## Token changes vs v1
- All **semantic role names are unchanged** (`--color-primary`, `--color-accent`, `--color-verdict-scam-*`, and so on), so app code needs no renames.
- `accent`, `accent-soft` and `on-accent-soft` now **alias brand teal**. The separate `accent-*` primitive ramp was **removed**, so Tailwind `accent-50…800` utilities no longer exist; use `brand-*`.
- New primitives: `brand-*` (teal), `neutral-*` (zinc, including 150/850), and `tool.nemotron` / `tool.tavily`.
- New `shadow_dark` set.
